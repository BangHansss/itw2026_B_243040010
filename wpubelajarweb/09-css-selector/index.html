Struktur & Hasil Selector.

01

Tag & Grouping Selector

Menargetkan tag HTML langsung (seperti h4) dan menggabungkan beberapa tag dengan koma.

Contoh Heading 4 (Tag Selector)

Teks ini diatur menggunakan tag selector standar.

02

Kombinator Spasi

Memilih elemen di dalam elemen lain (contoh: tag a di dalam li di dalam ul).

  • Menu Item Pertama (ul li a)
  • Menu Item Kedua (ul li a)
03

ID & Class Selector

Menggunakan tanda pagar (#) untuk ID yang unik dan titik (.) untuk kelas.

ID Selector (#teks-id)
Class Selector (.teks-class)
04

Compound Selector

Menggabungkan tag dan kelas secara langsung (contoh: p.khusus) agar lebih spesifik.

Paragraf khusus menggunakan selector gabungan (p.khusus).
